# About This Guide

This guide explains how to create, configure, secure, run, and troubleshoot Intelligent Processor Automation (IPA) workflows in **InSight DXP**.

If you are new to IPA, start with the IPA overview and key concepts. Then, build your solution workflow step by step.

For existing workflows, refer to the topics about managing node configurations, credentials, and execution history. Each procedure includes an expected result to help you verify the configuration.

## What This Guide Helps You Do

- Access IPA through InSight DXP.
- Create a workflow that represents the solution.
- Select and configure nodes for the required tasks.
- Apply credentials to authenticated integrations.
- Review workflow executions to understand results and troubleshoot issues.

## Target Audience

This guide is primarily intended for the **Professional Services Implementation team** and the **product development team**.
